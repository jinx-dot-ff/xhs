小红书笔试 评里找完整开发交付
整理日期：2026-10-11

先看 README.md，再将整个文件夹交给其他 AI，并要求它阅读 AI开发交接.md。
Windows 双击 启动预览.cmd；其他系统在本目录执行 node server.cjs。
需要 Node.js 18+，无需安装 npm 依赖，无需 API 密钥。
默认 http://127.0.0.1:8765/app/index.html，端口占用时以终端输出为准。
双击 验证交付.cmd 可以执行检索测试与文件/素材/服务检查。

app 内代码和图片是用户最新标注之后的实现；正文、评论、回复和评论输入提示统一13px；首页卡片标题不加粗，点赞数显示完整数字；手机框使用iPhone15Pro机身比例，点击搜评论在原输入栏替换且不自动滚动。
原始PNG、优化WebP、用户界面参考图、全部虚构数据、原PRD、最新AI开发交接、图标许可和验收截图已放在同一目录。
首页左上角菜单仅展示，无法点击；不要按旧说明恢复其重置入口。
相关评论是本地演示检索，不是真实大模型服务。浏览器本地操作数据没有导出，原始数据及行为完整包含在代码中。
